## Notes
KNOWN ISSUE:
- WSA wont work after being installed on some win11 builds im finding. 

When installing with this installer, there can be situations where the installer will finish and tell you that you need to reboot to finish the installation. 
In this case, after a reboot the installer will launch itself upon login and automatically finish the isntallation. 

If you are downloading the needed files via the installer and you are experencing slow download speeds, downlaod the zip parts from the Installer-Data folder in this repo. 
You need to get the ```WSA_Gapps.zip.00X``` and the ```WSA UserData [RVX + YT + MicroG + FX File Explorer + GApps].zip.00X``` files from the User-App-Data folder. 
Use a download manager like Xtreme Download Manager to get better download speeds.
Once all the zip parts have been downloaded, put all the files in a folder called Temp and put that folder in the same directory that the WSA Setup.exe file is located. 
Once it detects that the temp folder is present, and all the needed files are in it, it will skip downloading of the files and go straight to installing.
